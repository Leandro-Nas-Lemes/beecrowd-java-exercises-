# 💻 Beecrowd Java Exercises

Repositório com soluções de exercícios do Beecrowd em Java, focado em lógica de programação e manipulação de strings.

---

## 📌 Exercícios

### 🔹 Text Justification
- Remoção de espaços extras
- Alinhamento à direita
- Uso de arrays e loops

---

## 🧠 Conceitos aplicados

- Manipulação de Strings
- Estruturas de repetição (for, while)
- Arrays
- Entrada e saída de dados

---

## 📈 Objetivo

Evoluir habilidades para atuar como desenvolvedor e analista de sistemas/dados.
